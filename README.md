### 🚀 Featured Projects

**[E-Commerce Delivery SLA Analysis](https://github.com/gurvinder604/ecommerce-sla-analysis)**
Analysed 96,470 orders to identify SLA breach drivers using Python, SQL, and a 3-page interactive Power BI dashboard. Found carrier delivery time — not seller processing — as the dominant breach driver, plus a 2.5x state-level breach disparity.
`Python` `SQL` `Power BI` `pandas`

**[US Flight Delay Root Cause Analysis](https://github.com/gurvinder604/flight-delay-analysis)**
Analysed 2.99M flight records, quantifying $978.1M in carrier delay costs and identifying late-aircraft propagation as the top delay driver, visualised in a 3-page Power BI dashboard.
`Python` `SQL` `Power BI` `Matplotlib` `Seaborn`
